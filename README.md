# 📚 StudyMate

**StudyMate** adalah aplikasi mobile personal academic organizer yang membantu mahasiswa mengelola kebutuhan akademik dalam satu tempat. Aplikasi ini dirancang untuk menyimpan dan mengatur jadwal mata kuliah, materi pembelajaran, tugas, serta deadline secara lebih terstruktur.

StudyMate tidak hanya berfungsi sebagai pengingat jadwal kuliah, tetapi sebagai pusat pengelolaan aktivitas akademik pribadi mahasiswa.

---

## 🎯 Latar Belakang

Mahasiswa sering menyimpan informasi akademik di berbagai tempat, seperti screenshot jadwal, file PDF, catatan pribadi, chat, dan aplikasi pencatat lainnya. Kondisi tersebut dapat membuat informasi mata kuliah, materi, tugas, dan deadline menjadi kurang terorganisir.

StudyMate dikembangkan sebagai solusi untuk mengumpulkan informasi akademik tersebut ke dalam satu aplikasi yang dapat dikelola secara personal oleh masing-masing pengguna.

---

## 💡 Fitur Utama

### 🔐 1. Authentication & Profile

Pengguna dapat membuat akun dan masuk ke dalam aplikasi menggunakan akun masing-masing.

Fitur yang tersedia:

- Login
- Register
- Demo User
- Logout
- Session pengguna
- Edit Profile
- Informasi pengguna

Setiap pengguna memiliki data akademik yang terpisah sehingga data pengguna lain tidak ditampilkan.

---

### 📅 2. Course Management

Pengguna dapat mengelola data mata kuliah secara mandiri.

Fitur yang tersedia:

- Menambahkan mata kuliah
- Mengedit mata kuliah
- Menghapus mata kuliah
- Melihat daftar mata kuliah
- Menyimpan informasi dosen
- Menyimpan kelas
- Menyimpan hari dan jam
- Menyimpan ruangan

---

### 📷 3. Smart Schedule Import

StudyMate menyediakan fitur untuk membantu pengguna memasukkan jadwal kuliah dari file atau gambar.

Alur fitur:

```text
Upload Screenshot / PDF
        ↓
OCR / Schedule Processing
        ↓
Extract Schedule Data
        ↓
Review Schedule
        ↓
Edit / Delete / Add
        ↓
Save to Courses
